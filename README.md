# Multi-modal-AI-Detector
A CNN-based multi-modal AI detection system that detects AI-generated images, identifies their source models, and analyzes videos to determine the presence of AI-generated content.

## Features
- AI Image Detection (Real vs AI)
- AI Model Identification (DALL·E, MidJourney, Stable Diffusion, etc.)
- AI Video Detection (Frame-based analysis)

## Tech Stack
- Python (Flask)
- TensorFlow / Keras
- OpenCV
- HTML, CSS, JavaScript
